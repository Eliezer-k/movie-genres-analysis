Movie Genres Analysis

Objective
Analyze movie datasets to identify trends in genres, popularity, and revenue.

---
Tools Used
- Python (Pandas, NumPy)
- Power BI
- Matplotlib / Seaborn

---
Dataset
Movie dataset (IMDb / TMDb)

---
Key Insights
- Drama is the most frequent genre
- Action movies tend to generate higher revenue
- Genre popularity has evolved over time

---
Project Structure
- data/ → dataset
- notebooks/ → analysis code
- dashboard/ → Power BI dashboard
- images/ → visualizations
